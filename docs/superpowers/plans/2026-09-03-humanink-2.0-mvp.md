# HumanInk 2.0 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 HumanInk 重构为 DSH 原生、本地文件真源、Agent 与 UI 共用上下文的内容工作台 MVP。

**Architecture:** 保留 Core、Storage 和现有 Harness 应用能力，新增 Workbench Service、文件项目适配器和 DSH Remote/Tool/Skill/Prompt 适配层；Client 改为内容侧栏与按需内容检查器。旧命令和旧数据读取在 0.9.x 保持兼容。

**Tech Stack:** TypeScript 5、React 18、Vitest、tsdown、pnpm 11.7.0、DeepSeek Harness Cordis/Slots/Remote/Tools。

## Global Constraints

- Windows 是发布阻断平台。
- Better Sidebar 只能是 optional enhancement，不能是启动依赖。
- 旧 `/humanink-*` 命令至少保留一个 Minor 版本。
- AI 写入必须创建新版本，不静默覆盖正式稿。
- 密钥只在 Host Credentials Service 使用。
- 每个任务更新版本/CHANGELOG、自测并创建独立 Git commit。
