# HumanInk dsh Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `dsh web` 内交付可安装、可测试的 HumanInk 三栏内容工作台，并保持现有命令工作流兼容。

**Architecture:** Host 侧在现有 `HumanInkApplication` 上增加框架无关 UI facade；Browser 侧为独立 client package，以可注入 API 和 transport adapter 驱动状态模型与 Web Component UI，并通过 Harness slots 注册入口和 Overlay。根 Bundle 同时导出 Host 和 `./client` 入口。

**Tech Stack:** TypeScript ES2022、Vitest、jsdom + Playwright、React 18、CSS、pnpm workspace、tsc、tsdown、DeepSeek Harness Cordis client slots。

## Global Constraints

- 产品品牌保持 `HumanInk`，安装包/Bundle 保持 `dsh-humanink`，命令保持 `/humanink-*`。
- UI 必须集成在 `dsh web`，不得恢复独立静态 Demo。
- AI 输出与手工保存必须创建新内容版本，不覆盖既有版本。
- 目标版本为 `0.7.0`，更新 `VERSION`、所有 package version、`CHANGELOG.md`、README 和使用文档。
- 每个实现步骤遵循 TDD；交付前运行完整测试、typecheck、build、bundle 和 pack 验证。
